# Ironvale Gym — Landing Website

Premium, responsive marketing site for **Ironvale Gym**.

Pure static HTML, CSS and vanilla JavaScript. No build step. Photos are original AI-generated images in `assets/img/`.

Working features:
- Live open/closed status from the visitor's local time
- Membership plans with monthly/yearly toggle (yearly −15%)
- Join, free consultation (choose a coach) and free trial booking flows with validation and confirmation reference
- Brand-film preview modal, gallery lightbox (arrows/keyboard), trainer carousel with dots
- FAQ accordion (one open at a time), newsletter signup, mobile menu, scroll reveals

Run locally: `python3 -m http.server 8080` then open http://localhost:8080

Before launch: replace sample prices, address, phone, stats and trainer names with real details, and connect forms to your CRM or booking system.
